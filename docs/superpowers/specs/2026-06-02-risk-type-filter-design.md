# 风险类型筛选框实时数据设计

## 目标

事件页只保留一个“风险类型”树形筛选框。树中始终展示完整攻击目录，但是否可勾选以及
学习器数量必须由 `/risk/attack-types?scope=event&includeCount=true` 的实时返回决定。

## 数据来源

- 前端静态目录只保存一级分类、中文名称和后端正式 `attack_type` 编码。
- 后端接口从当前 session 的学习器记录读取 `rule_json.attack_types[0]`，按主攻击类型统计
  学习器数量。
- 前端不得使用 Mock 编码发起筛选请求。
- `UNKNOWN_SUSPECTED` 作为运行时兜底类型，在目录中展示为“未命名攻击”。

## 交互规则

1. 删除“旧版风险类型”筛选框。
2. 接口返回且 `count > 0` 的叶子节点映射为 `available=true`，可以勾选。
3. 未返回、`count = 0` 或尚未实现的叶子节点置灰。
4. 一级分类没有任何可选子项时置灰。
5. 勾选一级分类时，只选择当前可用的子项。
6. 筛选请求仅提交后端正式 `attack_type` 编码。

## 验证

- TypeScript 编译和 Vite 生产构建通过。
- 后端测试确认接口按 `rule_json.attack_types[0]` 统计，每个学习器只计入一种类型。
- 扫描事件页代码，确认不再引用 Mock 风险树和旧版风险类型状态。
